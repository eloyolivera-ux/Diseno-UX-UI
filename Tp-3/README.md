# TP3 - HTML y CSS

## Ejercicios resueltos

Se resolvieron todos los ejercicios del trabajo. A lo largo de los ejercicios se trabajó con formularios, tablas, selectores CSS, modelo de caja, pseudo-clases, posicionamiento, variables CSS, simulación de modo oscuro y diseño responsive utilizando Media Queries.

A medida que se fue avanzando, se fueron comprendiendo mejor los conceptos relacionados con la estructura de una página web utilizando HTML y cómo se puede modificar su apariencia y comportamiento mediante CSS.

Los ejercicios que se resolvieron son:

* **Ejercicio 1:** Estructura HTML básica.
* **Ejercicio 2:** Listas y enlaces.
* **Ejercicio 3:** Tabla de datos.
* **Ejercicio 4:** Formulario simple.
* **Ejercicio 5:** Primeros estilos CSS.
* **Ejercicio 6:** Selectores CSS.
* **Ejercicio 7:** Box Model.
* **Ejercicio 8:** Flexbox y barra de navegación.
* **Ejercicio 9:** Flexbox y galería de tarjetas.
* **Ejercicio 10:** CSS Grid y distribución de la página.
* **Ejercicio 11:** Pseudo-clases y pseudo-elementos.
* **Ejercicio 12:** Posicionamiento con `fixed`, `absolute` y `relative`.
* **Ejercicio 13:** Formulario estilizado.
* **Ejercicio 15:** Diseño responsive y Media Queries.
* **Ejercicio 16:** Animaciones con `@keyframes`.
* **Ejercicio 17:** Menú hamburguesa utilizando solamente HTML y CSS.
* **Ejercicio 18:** Galería tipo mosaico con CSS Grid.
* **Ejercicio 19:** Formulario multi-step con validación visual.
* **Ejercicio 20:** Landing page completa integrando diferentes conceptos del TP.

## Decisiones de diseño relevantes

### Ejercicios 1, 2 y 4

En los primeros ejercicios se decidió no aplicar CSS, ya que fueron los primeros pasos en HTML y los estilos se comenzarían a trabajar en ejercicios posteriores.

### Ejercicio 5

Se reutilizó la estructura del Ejercicio 1 mediante una copia del archivo HTML (`index1copy.html`) y se incorporó CSS externo para comenzar a trabajar con estilos.

### Ejercicios 13 y 14

Se reutilizó la estructura del formulario trabajado anteriormente, realizando modificaciones y agregando nuevos estilos para continuar incorporando conceptos de CSS.

### Ejercicio 15

Se reutilizó la estructura del Ejercicio 10 (`index10copia.html`) para agregar el diseño responsive mediante Media Queries.

Se utilizó el enfoque **Desktop First** porque se partió de un diseño del Ejercicio 10 que ya estaba pensado para pantallas de escritorio. A partir de esa estructura se realizaron modificaciones para adaptar la página a pantallas de menor tamaño.

### Ejercicio 16

Se reutilizó la galería realizada en el Ejercicio 9 (`index9copia.html`) para incorporar animaciones mediante `@keyframes`.

### Ejercicio 17

Se continuó utilizando la galería y las imágenes de productos de ejercicios anteriores, agregando un menú hamburguesa realizado solamente con HTML y CSS.

### Ejercicio 18

Se reutilizaron las imágenes de productos de los ejercicios anteriores para crear una nueva distribución tipo mosaico utilizando CSS Grid.

### Ejercicio 20

Se reutilizaron nuevamente las imágenes y la temática trabajada anteriormente para construir la landing page final, incorporando los distintos conceptos aprendidos durante el TP.
